# Pinned environment for reproducing results/README.md

# Why this file is pinned and not a loose range
# ----------------------------------------------
# Run 14 measured B1 at 0.790 pooled where Run 2 measured 0.780 -- the same model, the same data,
# the same seeds. The cause was scikit-learn: the local runs use Anaconda's build, the Modal image
# installs from PyPI, and `MLPRegressor` differs between them by about 0.010 Spearman. Locally the
# pipeline reproduces Run 2 exactly (maximum per-row difference 0.0), so the discrepancy is
# environmental, not stochastic.
#
# A 0.010 drift is the same size as several differences this project reports as findings. Without
# a pin, a reader re-running the code could reasonably conclude a number was wrong.
#
# Versions recorded 2026-10-04 from the environment that produced every figure in
# results/README.md, except where a run is marked as having executed on Modal.
#
#   python 3.13.5 (local)   /   python 3.11 (Modal images)
#
# To reproduce the LOCAL runs:   pip install -r requirements.txt
# To reproduce the MODAL runs:   python -m modal run modal_app.py::<entrypoint>
#                                (the image is built from modal_app.py and pins nothing further;
#                                 see the note below)
